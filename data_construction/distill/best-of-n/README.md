# Shared Answer-Likelihood Best-of-N

This directory selects one rollout from the four candidates generated by any
of the 9B, 27B, or 122B stages. Use the same model preset as the rollout stage
in `config.yaml`.

```bash
bash launch.sh config.yaml
python3 status.py --config config.yaml
python3 merge_shards_to_splits.py --config config.yaml
python3 build_final_rollouts.py --config config.yaml --overwrite
```
